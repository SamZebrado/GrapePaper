# CHANGED FILES — GrapePaper v0.1 Delivery Fix

## Summary

Root cause of `Cannot find native binding` / `@rolldown/binding-darwin-arm64`:
Vite 8 switched its default bundler from esbuild (pure JS) to Rolldown (Rust native binary).
Rolldown requires platform-specific native bindings that are not available on all OS/arch combinations.

Fix: Pin Vite to v6 (last stable esbuild-based release). This eliminates all native binding requirements.

## Dependency Version Changes

All packages pinned/downgraded to reduce upgrade surface and align with the chosen Vite 6 + React 18 stack. Vite 8 was the direct trigger (it defaults to Rolldown, which has native binding issues on some platforms); the rest were aligned to maintain a consistent, well-tested combination.
